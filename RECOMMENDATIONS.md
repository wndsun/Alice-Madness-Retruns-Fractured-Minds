# Recommendations

### General Recommendations

I recommend that both players connect at the same time! This helps prevent game synchronization issues.

If you or the client encounter a noticeable bug, try restarting the level. If that doesn't work, try returning to the main menu and selecting **Continue**.

**Most importantly!** Both players should remain in the main menu until they are ready to connect. If you're the host, make sure the client has selected their save file at the beginning of the game and has entered the main menu. This ensures that both players connect at the same time.

**If one player has the EA version and the other has the Steam version, I recommend the following:**
- The player with the Steam version should always be the host.
- The player with the EA version should always be the client.
This is recommended to prevent synchronization issues and bugs.

### What should you do if you get stuck or the other player is far away?

There is a teleportation system that allows you to teleport to your partner.

- **If you're the host:** Press **P** to teleport to the client.
- **If you're the client:** Press **O** to teleport to the host.

Teleportation can often solve these problems!

### Important!

If restarting the game or the level doesn't fix the bugs, try selecting a different chapter first, then return to the chapter you actually want to play.

Also, remember to delete the files located in the `AliceCoop\client-saves` folder to remove the most recently saved checkpoints. **This must be done by the client.**

If the game crashes during startup or at certain points while playing, try launching the game again.

### What should you do if the client's dress is broken?

Don't worry! If the host is playing as London Alice, ask them to move forward a little so that the dress can fix itself.

If that doesn't work, try switching roles. For example, the client becomes the host, and the host becomes the client. This should resolve the dress issue.

### Advice for the Host

Stay in place and always wait until the client's game has fully loaded. The client should let you know when their game is ready.

### Cutscenes

This is also important to prevent crashes and bugs.

If you're the host, you must wait until the client's game has fully loaded. Once the client confirms that they're ready, you can skip the cutscene.

### Crash Logs

There is a folder called `CrashDump` in the game directory. It stores records of game crashes. Files only appear in this folder when a crash occurs.

Make sure to clean this folder regularly, as accumulated crash dump files can take up additional disk space!

### Final Note

Please keep in mind that this mod may not always work perfectly. You may encounter bugs, crashes, or other issues while playing.

If you have any questions or encounter problems, please report them here: https://github.com/wndsun/Alice-Madness-Retruns-Fractured-Minds/issues

**Have fun playing!**
