# Recommandations

### Recommandations générales

Je recommande aux deux joueurs de se connecter en même temps ! Cela permet d'éviter les problèmes de synchronisation du jeu.

Si vous ou le client rencontrez un bug notable, essayez de redémarrer le niveau. Si cela ne fonctionne pas, retournez au menu principal et sélectionnez **Continue**.

**Le plus important !** Les deux joueurs doivent rester dans le menu principal jusqu'à ce qu'ils soient prêts à se connecter. Si vous êtes l'hôte, assurez-vous que le client a sélectionné son fichier de sauvegarde au début du jeu et qu'il est entré dans le menu principal. Cela garantit que les deux joueurs se connectent en même temps.

**Si un joueur possède la version EA et l'autre la version Steam, je recommande de procéder comme suit :**
- Le joueur qui possède la version Steam doit toujours être l'hôte.
- Le joueur qui possède la version EA doit toujours être le client.

Cette configuration est recommandée afin d'éviter les problèmes de synchronisation et les bugs.

### Que faire si vous êtes bloqué ou si l'autre joueur est trop loin ?

Un système de téléportation vous permet de rejoindre votre partenaire.

- **Si vous êtes l'hôte :** appuyez sur **P** pour vous téléporter auprès du client.
- **Si vous êtes le client :** appuyez sur **O** pour vous téléporter auprès de l'hôte.

La téléportation peut souvent résoudre ce genre de problèmes !

### Important !

Si le redémarrage du jeu ou du niveau ne corrige pas les bugs, essayez d'abord de sélectionner un autre chapitre, puis revenez au chapitre auquel vous souhaitez réellement jouer.

Pensez également à supprimer les fichiers situés dans le dossier `AliceCoop\client-saves` afin de supprimer les points de contrôle sauvegardés les plus récemment. **Cette opération doit être effectuée par le client.**

Si le jeu plante au démarrage ou à certains moments pendant la partie, essayez de le relancer.

### Que faire si la robe du client est cassée ?

Ne vous inquiétez pas ! Si l'hôte joue avec London Alice, demandez-lui d'avancer un peu pour que la robe puisse se réparer automatiquement.

Le plus important est que l'hôte utilise impérativement la version Steam.

### Conseils pour l'hôte

Restez sur place et attendez toujours que le jeu du client soit entièrement chargé. Le client doit vous prévenir lorsque son jeu est prêt.

### Cinématiques

C'est également important pour éviter les plantages et les bugs.

Si vous êtes l'hôte, vous devez attendre que le jeu du client soit entièrement chargé. Une fois que le client confirme qu'il est prêt, vous pouvez passer la cinématique.

### Journaux de plantage (Crash Logs)

Un dossier appelé `CrashDump` se trouve dans le répertoire du jeu. Il contient les rapports de plantage du jeu. Les fichiers n'apparaissent dans ce dossier qu'en cas de plantage.

Pensez à nettoyer régulièrement ce dossier, car l'accumulation de fichiers de rapport peut occuper de l'espace supplémentaire sur votre disque !

### Remarque finale

Veuillez garder à l'esprit que ce mod ne fonctionnera pas toujours parfaitement. Vous pourriez rencontrer des bugs, des plantages ou d'autres problèmes pendant vos parties.

Si vous avez des questions ou rencontrez des problèmes, veuillez les signaler ici :

https://github.com/wndsun/Alice-Madness-Retruns-Fractured-Minds/issues

**Amusez-vous bien !**
