Кооперативный режим для двух игроков в PC-версии *Alice: Madness Returns*.

Основан на / является форком проекта [Alice Co-op](https://github.com/docwitson/Alice-Madness-Returns-Co-op), созданного Docwitson, и построен на базе [MadnessPatch](https://github.com/Wemino/MadnessPatch).

### Скачать

**`AliceFracturedMinds-1.0.0.zip`** — распакуйте архив в папку `<game>\Binaries\Win32` (там, где находится `AliceMadnessReturns.exe`). Оба игрока должны использовать одну и ту же версию мода.

### Быстрый запуск

1. Запустите игру обычным способом (через Steam / EA App) и нажмите **M**.
2. Хост (Host): выберите *Host* → *Save* (запустится ретрансляционный сервер).
   Клиент (Client): выберите *Client*, введите LAN/VPN-адрес хоста → *Save*.
3. Перезапустите игру после смены роли. Хост начинает игру, а клиент нажимает **L**, чтобы присоединиться.

Полное руководство: [docs/INSTALL.md](https://github.com/wndsun/Alice-Madness-Retruns-Fractured-Minds/blob/main/docs/INSTALL.md)

### Что нового по сравнению с Alice Co-op 0.1.0-alpha.1

- Внутриигровое меню кооператива (**M**): выбор роли, адреса и порта сервера; хост может запустить сервер прямо из меню. Внешний лаунчер не требуется.
- Возможность наблюдать за хостом в главах Лондона.
- Синхронизированная погоня Палача: попадания, отбрасывание, смех и завершение погони.
- Общие появления врагов после смерти, перезапуска и продолжения игры.
- Множество исправлений вылетов (повторное появление, смена карт, удаление врагов).
- Исправлены дублирующиеся враги после продолжения игры, рассинхронизация при пропуске кат-сцен, столкновения с Elite Card Guard и несовпадение контрольных точек при продолжении игры из главного меню.
- Новые параметры `AliceCoop.ini`: `GameConsole`, `Logs`, `Dumps`.

Полный список изменений: [CHANGELOG.md](https://github.com/wndsun/Alice-Madness-Retruns-Fractured-Minds/blob/main/CHANGELOG.md)

### Требования

- Лицензионная PC-копия игры для каждого игрока (Steam или EA App). Файлы оригинальной игры в архив не входят.
- Windows 10/11, Microsoft Visual C++ 2015-2022 Redistributable **x86**.
- Один и тот же компьютер, локальная сеть (LAN) или надёжная VPN (например, Radmin VPN).

> [!WARNING]
> Ретрансляционный сервер не имеет аутентификации и шифрования. Никогда не открывайте его порт (UDP 27018) для доступа из Интернета.
>
> Архив заменяет файлы `dinput8.dll` и `MadnessPatch.ini`. Сделайте их резервные копии, а также сохраните резервные копии своих игровых сохранений.

### Сообщение об ошибках

Журналы (логи) по умолчанию отключены. Установите `Logs = 1` в секции `[Debug]` файла `AliceCoop\AliceCoop.ini`, воспроизведите проблему и приложите файлы из папки `AliceCoop\logs` к [сообщению об ошибке](https://github.com/wndsun/Alice-Madness-Retruns-Fractured-Minds/issues).
